## 🚀 Featured Projects

### 🔎 [ci-logs-classifier](https://github.com/AzizMadhbouh/ci-logs-classifier)
End-to-end **CI failure intelligence** pipeline: ingests Jenkins builds, classifies failures with a fine-tuned **ModernBERT** model, scores severity, stores results in **PostgreSQL**, and visualizes them in **Grafana**.
- 10-class baseline: **F1 0.77** on 14,320 eval samples; extended to **32 classes**
- Production guardrails: tool-output pre-filters, confidence rejection, LLM adjudication, drift logging
- **84 tests green** · Docker Compose · Alembic migrations · Ruff-clean

`Python` `PyTorch` `PostgreSQL` `Grafana` `Docker` `Jenkins` `NLP`

### ⚡ [ev-analytics-spark-hadoop](https://github.com/AzizMadhbouh/ev-analytics-spark-hadoop)
Distributed analytics pipeline over the **Electric Vehicle Population** dataset using **HDFS + YARN + Spark**, fully containerized with Docker Compose — 3 DataNodes, YARN ResourceManager, and a Spark cluster of workers.
- PySpark aggregations: top states/cities/makes, model-year trends, BEV vs PHEV, avg. electric range

`PySpark` `Hadoop HDFS` `YARN` `Docker`

### 🛒 [mapreduce-purchases-analytics](https://github.com/AzizMadhbouh/mapreduce-purchases-analytics)
**MapReduce** pipeline (Hadoop Streaming) processing **~4.1M purchase records** to compute total sales and transaction counts per category.

`Python` `MapReduce` `Hadoop Streaming`

### 🩺 [NoShowAnalysis](https://github.com/AzizMadhbouh/NoShowAnalysis)
Healthcare analytics project predicting **medical appointment no-shows** with feature engineering and baseline ML models.

`Pandas` `scikit-learn` `Jupyter`
